# Debtshare Frontend

A web frontend application to manage shared expenses simply, quickly, and collaboratively. It allows you to create groups, record payments, split costs among participants, and keep track of debts visually.

## Main features

- Scan tickets and invoices to quickly capture expenses
- Create and manage expense groups
- Register participants and assign expenses
- Automatically split costs among group members
- View balances, debts, and pending payments
- History of movements and group activity
- Responsive design for mobile and desktop use
- Integration with backend services for authentication and data persistence

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios

## Project structure

- `src/` — components, pages, hooks, and services
- `src/components/` — reusable UI elements
- `src/pages/` — main application views
- `src/services/` — API calls and integration logic
- `src/utils/` — utilities and helpers

## Prerequisites

- Node.js 18 or higher
- npm or pnpm

## Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   cd debtshare-frontend
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the application in your browser at the URL shown by Vite.

## Available scripts

- `npm run dev` — starts the development environment
- `npm run build` — builds the app for production
- `npm run preview` — previews the production build locally
- `npm run lint` — runs the linter

## Usage flow

1. Sign in or create an account.
2. Create an expense group.
3. Add participants.
4. Record expenses from a ticket or invoice.
5. Review balances and simplify debts between members.
